## 一、决策一：已落地（v0.12.10）

### 改法（只动 core.js + 版本戳）

- **关系标签搬进 badge 盒子**：`badgePaint` 新增 `rel` 参数，附加位（拉黑钮之后）优先渲染关系标签；`relChipRow` 停画名字行的独立节点，只负责摘历史遗留节点。位置从「名字锚 afterend」变成「badge 盒子里、拉黑钮之后」，正是用户点名的 @handle 那一行、与拉黑同一处。
- **百分比收进悬浮弹卡**：新增 `relBadgeTip`/`relBadgeRows`/`relBadgePop*`/`bindRelBadgeHover`，hover 关系标签弹卡显示：关系档位、**关注百分比**（ratioInfo：正在关注/关注者）、**关注事件**（followStartAt：日期 + 来源「本机在关注列表里看到 TA 的那天」）、未回关天数。弹卡是 fixed 自家节点（data-xprobe=relpop），200ms 延迟收卡、可挪鼠标进去。
- **兜底不丢机制**：关系判不出时，附加位退回原来的百分比标签（art-008 那套宽度预算/粘性/退让/旧数机制原样保留，测试不失真）。窄缝装不下附加位时先丢标签只保拉黑钮，账记 badgeRatioNo/badgeRelNo。
- **清场纪律**：`badgeSweep` 调 `relBadgeSweep` 摘弹卡，关闸/切页不留半空；关系标签本体仍 pointer-events:none（不拦光标、不打断 X 点击），悬浮事件挂在自家 badge 盒子上——**不在 X 的节点上**。
- **修了一个真 bug**：`relChipRow(null)` 的摘除范围（UserCell）会把 badge 盒子里新关系标签一起摘掉（同 data-h）；加 `data-role=rel` 排除，badge 盒子内的标签由 badgePaint 全权管。
- **主题就地重刷**：粘住分支里若 `data-t` 与当前主题不符，就地 relChipStyle 重刷配色，不换节点（深浅翻面不抖）。

## 二、决策二：评论数读 API —— 实测确认 + 待授权方案

### 实测结论（不是看代码猜，是真连库查）

| 数据源 | 结论 | 证据 |
|---|---|---|
| **pg16 主库** `82.157.203.250:15432/zhishu` | 连上，**33 张表**，`x_observe_*` 系列齐全，**没有任何 comment/reply/评论表** | `information_schema.tables` 全量枚举 |
| **本机 xprobe.db** `temp/xprobe/xprobe.db` | **16 张表**，无评论表；`tweets` 里评论当帖子存、`reply` 只是回复数 | `sqlite_master` 全量枚举 |
| **本机 pg（127.0.0.1:5432）** | CMS 镜像库，密码不同、与观测数据无关 | start-local-online.ps1 CMS_DATABASE_URL 注释 |

用户记忆里的"评论表"很可能是 `x_observe_post`（帖子表）——评论行会当普通帖子落进去，但它是帖子结构（author/text/view/reply），**没有"谁回复谁"的关系字段**，算不出"我给他/他给我评论几条"。

### 为什么"读现成 API"走不通（四层全缺）

1. **采集层**：只采 `reply` 计数，没有评论者 handle、回复目标、own 标记。评论行虽当 article 扫进 `tweets`，但无父子关系。
2. **存储层**：本机 16 表、pg16 33 表都无评论明细表。
3. **服务端**：zhishu 全部接口无评论口；`xSpacePost` 明确返回 `comments.collected:false`。
4. **通道**：扩展 host_permissions 无 x.com，不能主动问 X；SW 无通用云端只读查询消息。

### 待用户授权的落地方案（红线：跨仓库 + DDL + 重启服务，必须单独立项）

- **第一步（本机、最小）**：采集层加"评论作者 + 回复目标 + own 判断"，本机库加 `comments` 明细表，弹卡读本机账。零新出口。代价：只能统计扩展装着以后发生的评论，历史补不回。
- **第二步（云端）**：pg16 加迁移表 + 上传接口 + 查询接口 + 扩展读通道。要执行 DDL、重启 zhishu 服务、改 manifest/权限边界——**必须用户逐项授权后才动**。

本版弹卡里评论数那一栏**不显示数字**，脚注写"评论数本机未采集"——RL-11 不编数。
