# art-027 · 行内速率徽标悬浮详情 + 去掉页头左侧徽标（v0.12.8 / 2026-11-12-e）

## 1. 用户原话与诉求

> 「有两个问题，一个是帖子详情页顶部有一个、右侧有一个，左侧的能悬浮显示详情，右侧的不支持；另外评论区的悬浮也不支持。需要帮我给评论区的速率显示添加悬浮效果，另外帖子右侧的详情页添加悬浮效果，完善后给左侧的去掉。」

拆成三件事：
1. 帖子右侧那颗速率徽标 → 加悬浮详情卡；
2. 评论区每颗速率徽标 → 加悬浮详情卡；
3. 左侧（页头）那颗 → 悬浮能力迁走后**去掉**，避免同一条帖在页头 + 右侧重复显示两个 `47/h`。

## 2. 三处徽标的来源（改前）

| 位置 | 产生代码 | class / 挂点 | 悬浮 |
|---|---|---|---|
| 顶部左侧（页头 h2 后） | `hotDetStep()` | `HOTDET_CLS` = `ysy-xprobe-hotdet`，插在 h2 后 | 有（`bindDetHover`） |
| 帖子右侧（主贴 article 内） | `hotBadgeRender()` | `HOT_BADGE_CLS` = `ysy-xprobe-hotvel`，挂在每个 article | 无 |
| 评论区（每条评论 article 内） | `hotBadgeRender()` | 同上 | 无 |

悬浮详情卡机制（`hotDetPopOpen` / `hotDetPopShow` / `hotDetPopPlace` / 200ms 延迟收卡）本身是现成的，只是**数据源写死 `hotDetData()`（按 URL 定位主贴）**，所以行内徽标即便绑了悬浮，也会全部显示主贴数据 —— 这是不能直接照搬的原因。

## 3. 改法（只动 `extension/content/core.js`）

- **新增 `hotArtData(art)`**：从**任意一条 article** 取详情行。`tid = hotTidOf(art)`，精确读数优先（`netTweets[tid]` → `hotFromNet`），DOM 兜底（`hotParseArticle(art)`）。与 `hotDetData()` 的口径一致，但对象从「URL 指定的主贴」换成「徽标所在的这条帖子」。
- **`bindDetHover(chip, dataOf)`**：接受一个取数函数 `dataOf`；悬浮时调 `dataOf()` 拿这条帖子的数据喂详情卡。不传才退回 `hotDetData()`（兼容旧调用）。
- **`hotBadgeRender()` 给每颗行内徽标绑悬浮**：`bindDetHover(b, () => hotArtData(art))`。评论、主贴、时间线每一颗都用自己所在 article 的数据 —— 悬停评论显评论、悬停主贴显主贴。
- **`hotDetStep()` 不再造页头徽标**：变成只做「SPA 切走页头没了就把可能吊着的弹卡收掉」的清场，恒返回 0。`HOTDET_CLS` 造节点代码整段删除；`hotDetSweep()` 保留，兜底摘除任何遗留的页头节点与弹卡。
- **弹卡机制全部复用**：八栏详情、指纹去重（`hotDetPopKey`）、右下定位、200ms 延迟收卡、鼠标挪进卡取消收起 —— 一字未改，只是触发源从页头那颗换成行内每颗。

## 4. 有意没做 / 红线

- **守 RL-30**：悬浮是用户主动 `mouseenter` 事件，不在 X 渲染期往宿主节点写东西；详情卡是 `position:fixed` 挂在 `documentElement` 下的自有浮层，不插进 X 的 article，不会在评论增量加载时引起抖动。
- **守 RL-16**：监听只挂在自家 `HOT_BADGE_CLS` 徽标上（`data-hb` 防重复绑定），关闸 `hotBadgeSweep` + `hotDetSweep` 当场摘净徽标与弹卡。
- **零新出口 / 零新权限 / 零新节点种类**：没发一个请求、没加一个权限、没新增宿主节点类型；复用现有徽标与弹卡。
- **没碰宿主 Python**：按 RL-12 无需重打 exe；只改扩展侧 JS/JSON。

## 6. 真机走查（本环境无浏览器，需用户执行）

1. `chrome://extensions` ⟳ 重载，确认 `0.12.8`；打开「热」总闸（默认关）。
2. 进一张评论多的帖子详情页：页头「帖子」标题旁**不再**有速率徽标；主贴右侧与每条评论各有一颗速率徽标。
3. 鼠标悬浮**主贴右侧**徽标 → 出详情卡八栏，数值是主贴的；悬浮**任意评论**徽标 → 详情卡变成那条评论的数据（浏览量/点赞不与主贴混）。
4. 鼠标从徽标挪进详情卡 → 卡不消失；移开 → 约 200ms 后收起。
5. 滚动加载更多评论时页面不抖不飘（RL-30）；停滚后新评论行的徽标与悬浮可用。
6. 拨回总闸 → 所有行内徽标与详情卡当场摘净。
