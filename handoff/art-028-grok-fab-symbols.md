# art-028 · 右缘钮排 grok 同款黑底符号化 + 每颗单独开关（v0.12.9）

## 用户裁定

- **决策一**：选方案 1 —— 九颗汉字全换成一眼能懂的小符号，黑底白图，字号大降、间距收紧，照右下角 grok / 评论 / 头像那几颗的观感做；hover 仍弹中文全称。
- **决策二**：设置里能单独关某颗（点名关、稿、回），**关掉直接不显示不占位**（不是变灰、不是 display 占位）。
- 用户原话：「这个悬浮面板字体太大了，间距太宽了，和已有的 grok 等图标完全不成比例，请你严格按照页面原先的 grok 等按钮的大小和样式制作，并且能在设置中关闭某个选项，比如勾选关、稿、回。另外 探 不应该是个大字，而应该是一个⬇️的设计，小一点 一眼能看出来是个什么意思。」

## 截图取证

`clipboard-2026-11-12T08-49-32-286Z-7e2b1062.png`：左边探针柱每颗约 34~40px、单字约 20px、间距 6px、灰底描边；右下 X 自带 grok 是黑底圆角方钮 + 白色线条图标，评论气泡与 NB 头像同一套。症结是「大汉字 + 宽间距 + 灰描边」视觉太重，跟 grok 的「小图标 + 黑底 + 紧凑」不是一个路子——不是像素大小的问题。

## 改法（只动扩展侧，未碰宿主 Python）

### 一、符号化 + 黑底白图

| 钮 | 原汉字 | 新符号 | 语义 |
|---|---|---|---|
| 折叠「探」 | 探 | ▾ / ▴ | 向下展开、向上收起（随状态翻） |
| 关 | 关 | ☰ | 三横 = 名单 |
| 榜 | 榜 | ▤ | 表格 = 曝光榜 |
| 热 | 热 | ✦ | 星芒 = 热点 |
| 回 | 回 | ↩ | 回转箭头 = 待回关 |
| 杆 | 杆 | ◎ | 靶心 = 标杆账号 |
| 帖 | 帖 | ▦ | 网格 = 标杆帖子 |
| 稿 | 稿 | ✎ | 铅笔 = AI 草稿 |
| 观 | 观 | ◉ | 同心圆 = 观测灯空闲态；冷却/到顶仍读秒数字 |

- `FAB_GLYPH` 一处定义九颗符号，`benchFabText`/`benchPFabText`/回角标的字面判断全部改读它，角标数字（↩2、◎3）逻辑不变。
- `FAB_STY`：灰玻璃 → 纯黑底 `#000` + 白符号 `#f5f7fa` + 细白圈 `rgba(255,255,255,.14)` + 9px 圆角；点亮态由「绿字」改成「绿描边 + 绿微光」，白符号不翻色（守 grok 白图）。
- `fabGlyphPx`（新）：符号直径 0.46、12~20px 封顶，比原汉字小一号，像居中图标；**读秒数字仍走原 `fabFontSty`**，两条字号逻辑分开、互不干扰（守卫灯空闲 ◉ → 符号字号，读秒 68 → 数字字号）。
- 柱容器：gap 6→3px、内边距 9/7→6/5px、圆角 8→12px、厚玻璃 → 透明黑托盘，让每颗黑钮各自独立（grok 那几颗没有厚玻璃外壳）。
- hover 全称仍在 `data-tip` → 向左浮出的中文标签，认不出符号时悬停即见。

### 二、每颗单独开关（关掉不显示不占位）

- 新 GM 键 `ysy.xprobe.fabvis`：存 `{ [id]: false }` = 该颗藏掉；没记 / true = 显示。默认九颗全显。
- `FAB_VIS_IDS` = 八颗业务钮；**折叠钮「探」不在内**——关了它整排再也展不开。
- `setFabVis(id,on)`：写配置 → 清显隐影子 → 立刻 `fabBtn()`，关掉的当场 `display:none`（flex 里不占位），其余钮顺序不动。折叠/展开、AI 模型闸三层叠加不打架；关掉「观」时分隔线跟着藏，不留孤线。
- 面板设置页「显示哪些钮」新增八颗勾选框（☰关 / ▤榜 / ✦热 / ↩回 / ◎杆 / ▦帖 / ✎稿 / ◉观），`data-fab` 绑 id；JS 回显 + `change` 发 `setFabVis`，失败弹回勾选框（不让 UI 说谎）。
- `stateForPanel` 增 `fabvis` 字段（缺省按全显，兼容旧 core）；`CMDS.setFabVis` + SW 命令白名单放行。

## 有意没做

- 没把整根柱子去掉改成散钮：柱子承载折叠/拖动/呼吸点，去掉要重构交互，与这次症状不匹配；改成透明托盘已经让每颗看起来独立。
- 没给 grok 那种外发光：只在点亮态给绿微光，平时保持克制。
- 没动宿主 Python / 权限 / 出口（RL-2/3），只改扩展侧 JS/HTML/CSS/JSON ⇒ 按 RL-12 无需重打 exe。

## 存量判据同步（不是放宽）

符号化把钉死汉字/圆角/字号/玻璃底的断言改成新口径：观→◉、回2→↩2、杆3→◎3、「关榜回杆帖」→「☰▤↩◎▦」、圆角 6→9px、单字 20px→符号 18px（44px 钮→20px）、玻璃底→黑托盘 12px、state 加 fabvis、SW 白名单加 setFabVis。变异对照 A 的刀随建排显隐行改写，仍钉「DOM 与账分家」那个语义。

## 真机走查（本环境无浏览器，需用户走）

1. `chrome://extensions` ⟳ 重载确认 `0.12.9`，刷新 x.com。
2. 右缘那排应是九颗**黑底白符号**小钮（▾ ☰ ▤ ✦ ↩ ◎ ▦ ✎ ◉），和右下 grok/评论/头像观感一致；间距明显比原来紧。
3. 默认折叠只露 ▾；点一下展开整排、符号翻成 ▴；再点收起。

7. 增量加载评论/滚动时页面不抖（RL-30 未动）；关掉某颗后刷新页面仍在（配置落库）。
