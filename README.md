# X 观测探针（x-observe-probe）

> 你在 X 上看到的数，自己留下来。  
> 一颗只读的浏览器浮标 + 一个只属于你电脑的 SQLite 档案库。

- 形态：Chrome / Edge 扩展（MV3，Side Panel 面板）+ 本机 Python 接收端 / Native Messaging 宿主
- 版本：`0.11.17`
- 许可：MIT
- 作者：月川 · X [@benben2052243](https://x.com/benben2052243)

---

## 这是什么

一个装在浏览器里的「X 本机观测台」。

你正常刷 X，它在后台**只读地**把你看到的数字记进你自己电脑上的 SQLite：

- 关注 / 粉丝 / 帖子总数
- 每条帖子的曝光、回复、转帖、喜欢、引用、书签、观看
- 关注关系、待回关名单
- 创作者奖励页的「有效曝光」（隔天出的那个数）
- 账号分析页的每日实时曝光

然后给你一个面板：趋势曲线、日点表、榜单、转化率、到达日预测，以及几条只提醒、不动手的建议。

它不是爬虫，不是机器人，也不会替你点任何按钮。

**它不请求 X 的任何接口**：`manifest.json` 里根本没有 `x.com` 的 host 权限，声明层就发不出去。

## 它解决什么问题

| 你的痛点 | 它的做法 |
| --- | --- |
| 每天手动抄关注/粉丝，坚持三天就断 | 打开主页 / 帖子 / 列表页自动采集，只读 DOM，不需要你操作 |
| 官方分析只给最近 7 天 / 28 天，历史拿不到 | 每天一个点持续累积，存本机 `xprobe.db`，想要多长有多长 |
| 「有效曝光」和「实时曝光」混在一起，转化率算不清 | 拆成两列：有效曝光（奖励页，T+1）+ 实时曝光（分析页，当天增量），转化率单独一张折线 |
| 关注太快怕限流，限了多少全凭感觉 | 60 秒冷却读秒 + 15 分钟 / 24 小时滚动额度；到限只变红，绝不拦你 |
| 关注了一堆人，不知道谁从没互动过 | 按本机台账列「最该取关」，只出建议，永不自动取关 |
| 想给同行做长期对照 | 标杆账号 / 标杆帖子，六根轴任排，数据优先从本机库读 |

## 主要功能

**自动采集（只读）**

- 个人主页：关注、粉丝、显示名、关注关系、头部自报的帖子总数
- 帖子详情：曝光 / 回复 / 转帖 / 喜欢 / 引用 / 书签 / 观看 / 已点赞
- 关注列表、粉丝列表、时间线
- 每个数字记录来源（可见文本 / aria-label），抓不到的字段如实进「漏抓清单」，不编数
- 关注 / 粉丝比例标签：底色分档（≥95% 绿、85~95% 黄、<85% 红），只对悬停过的名片或进过主页的人出数

**关注节奏守卫**

- 60 秒冷却倒计时，多标签页共享一本账
- 15 分钟 / 24 小时滚动窗口额度与密集关注标记，到限只警告
- 右缘竖排按钮：守卫灯、本页曝光榜、待回关、标杆账号、标杆帖子、本页用户
- 本页曝光榜 / 时间窗历史榜（历史档只读本机库）
- 拉黑台账只记在你本机，不动 X 的屏蔽与关注

**本机档案库**

- SQLite（WAL），14 张业务表：`records`、`snapshots`、`tweets`、`user_rows`、`follow_events`、`stat_points`、`reward_points`、`day_rows`、`store_users`、`store_posts`、`blocks`、`benchmarks`、`bench_posts`、`dumps`
- 双通道写入：优先 Native Messaging 宿主；宿主不在自动回退本机 HTTP `127.0.0.1:8765`
- 断线先暂存在浏览器，**确认落库成功才清队列**
- 文件与清理：日志 / 转储 / 库分别统计占用，按文件名日期判断保留天数（默认 7 天），删文件要点两下，库里一行数据不会被自动删

**面板**

- 首页：今日卡片、关注进度、额度
- 我的：分钟线、曝光日线、转化率、日点表、可复制的日报摘要、50 万曝光 / 5000 粉 / 1 万粉到达日预测
- 广场：曝光榜、互动榜、最该取关
- 诊断：查库、测活、明细、性能账
- 设置：钉死自己的账号、开关、目标、本机文件与清理

## 架构

```
┌─────────────── Chrome / Edge ───────────────┐
│  content scripts（只读 DOM）                 │
│    host-shim.js + core.js + bridge.js(MAIN)  │
│  service worker（sw.js）                     │
│  Side Panel（sidepanel.html / .css / .js）   │
└───────────────┬─────────────────────────────┘
                │ ① Native Messaging（优先）
                │ ② HTTP 127.0.0.1:8765（回退）
                ▼
┌────────────── 本机（Python 3.10+）──────────┐
│  native/xprobe_host.py   ← 宿主（stdio 协议帧）│
│  log-sink.py             ← HTTP 接收端 + 日志  │
│  xprobe_db.py            ← 入库 / 查询 / 视图  │
│  xprobe_fs.py            ← 占用统计与清理      │
│              │                               │
│              ▼                               │
│      ~/xprobe/xprobe.db  +  logs/  +  dump/   │
└──────────────────────────────────────────────┘
```

数据目录取值顺序：环境变量 `XPROBE_DIR` → `~/xprobe`；HTTP 回退还可以用 `log-sink.py --dir` 指定。

## 快速开始

准备：Chrome 或 Edge 114+、Python 3.10+。本机宿主目前只打包了 Windows。

1. **加载扩展**  
   `chrome://extensions` → 打开「开发者模式」→「加载已解压的扩展程序」→ 选本仓库的 `extension/` 目录。

2. **装本机宿主（推荐）**  
   在扩展面板 → 设置 → 最底下「扩展 ID 与安装命令」里拿到 32 位 ID，然后：

   ```bash
   pip install pyinstaller
   py -3 native/install-host.py --ext-id <你的32位扩展ID>
   ```

   它会把宿主打包成 exe 并写入当前用户的注册表（不需要管理员）。装完点一次扩展卡片上的 ⟳，再刷新 x.com。

3. **不想装宿主也可以**  
   双击 `start-sink.bat` 走 HTTP 回退，功能一样，只是要一直开着那个窗口。

4. **首次使用建议改三项**  
   - 「我的账号」钉成你的 handle（最重要：认错一次账就记到别人名下）
   - 今日目标
   - 关注冷却的随机加时上限

**卸载**：移除扩展 + `py -3 native/install-host.py --uninstall` + 删除数据目录。停用扩展即彻底停止采集。

## 隐私与边界

这些不是口号，是代码里的写法：

- **只读 DOM**：不点击、不派发合成事件、不滚动、不写 cookie、不模拟鼠标、不自动翻页或导航
- **不请求 X 的接口**：`manifest.json` 没有 `x.com` 的 host 权限；页面里的 `bridge.js` 只旁听 X 自己的 fetch/XHR，请求与响应原样放行，不拦不改不延迟
- **默认纯本地**：默认档请求只发往 `127.0.0.1:8765` / `localhost:8765`，或 Chrome 自己拉起、你亲手注册的本机宿主；所有请求 `credentials: 'omit'`
- **上云是可选的一档，默认关**：只有你在设置里主动把运行模式拨到云端、并用邮箱验证码登录之后，「我的」指标、标杆台账和抓取档案才会额外发一份到 `api2.mingzhang.cc`（作者自建的一台服务器）。本机照存，两套账独立；关掉 = 只停上送，本机一个字节都不动。**不信任这台服务器就别开，或者把 `extension/background/sw.js` 里的云端地址换掉。**
- **没有内置密钥**：仓库里没有任何可用的 token / 密钥
- **建议永不变成动作**：「最该取关」只是一行字，扩展不会替你取关、关注、点赞、转发
- **对页面零痕迹可还原**：缝进 X 页面的只有昵称旁一颗徽标和主页一颗「☆/★」，默认开，设置里拨回关就当场摘干净，连补过的样式一起还回去
- **日志含你浏览过的账号与页面内容**：不需要时删掉整个数据目录即可

## 开发与自测

```bash
# 扩展 + 宿主逻辑：1678 条断言
node probe-selftest.js

# SQLite 入库 / 查询 / 清理：219 条断言
python -X utf8 db-selftest.py

# 已经打好 exe 的机器上：22 条帧级自检
py -3 native/exe-check.py
```

当前状态：`1678 / 0`、`219 / 219` 全绿（2026-11-07 实测）。

**改了本机那一侧任何 Python（`log-sink.py` / `xprobe_db.py` / `xprobe_fs.py` / `native/xprobe_host.py`）必须重跑 `install-host.py` 重新打包**，再点扩展卡片上的 ⟳。只重启 `start-sink.bat` 不管用——装了宿主的机器上扩展根本不走那条回退通道。

## 已知限制

- 本机宿主只打了 Windows 包；HTTP 回退在 macOS / Linux 上可用
- 英文界面部分可用，个别列可能抓不全
- 账号分析页的逐日数只在悬停气泡里，需要你把鼠标沿柱子扫一遍
- 云端同步目前只有「本机 → 云」一个方向
- 安装器还要手动抄一次 32 位扩展 ID
- 守卫额度上限（15 个 / 15 分钟、400 个 / 24 小时）是常量，面板只能调随机加时
