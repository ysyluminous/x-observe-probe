补历史 / 改数

总曝光 = 账号分析页的每日曝光；有效曝光 = 奖励页那个 90 天滚动累计读数照抄（面板显示时自动和前一天相减得出当日数，转化率 = 当日差分 ÷ 当日总曝光）。 空框 = 不动那列；缩写也能填（13.2K / 1.3万 → 换算成整数、行上标 ~ 非精确）。
每一行改完（离开输入框或按回车）就自动写进本机库（同一天按列合并，空框不动那列）；「删」整行删除。 补历史用表格下方的「+」行：默认自动取表里最早那天的前一日（不用手选，也能改）、存完日期自动 −1，往前连补一路点加号；顶部「加」是往后补（+1）。 两个日期框也都能直接改成任何过去的日子。补完回到面板，「我的」页四张折线（含转化率）会跟着长。
